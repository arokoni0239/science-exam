# True Clothing BD Ltd — Website

Corporate website for **True Clothing BD Ltd**, built from the company profile and styled in the spirit of modern apparel sourcing sites (Dongyi, PDS, TeamBD, Epsilon GS).

## Pages

- `index.html` — Home
- `about.html` — About & mission
- `services.html` — Services & process
- `products.html` — Product categories
- `contact.html` — Contact & enquiry form

## Preview locally

Open `index.html` in a browser, or from this folder run:

```bash
python -m http.server 8080
```

Then visit http://localhost:8080

## Content source

Company copy, product categories, certificates, and contact details are taken from `True-Clothing-BD-Ltd-Company-Profile.pdf`. Product and certificate images were extracted from the same profile.
